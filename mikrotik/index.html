DOCUMENTATION

Panduan penggunaan

Alur aman untuk menggunakan generator.

01 · Pilih versi

Pastikan RouterOS v6 atau v7 sesuai perangkat. Beberapa fitur hanya tersedia pada versi tertentu.

02 · Isi parameter

Gunakan nama interface dan alamat IP yang benar-benar ada pada router Anda.

03 · Review script

Baca setiap baris. Script firewall dan routing dapat memutus akses jika salah konfigurasi.

04 · Backup & Safe Mode

Export konfigurasi terlebih dahulu dan aktifkan Safe Mode dari Winbox/Terminal.

05 · Terapkan bertahap

Uji di lab atau router cadangan. Terapkan per bagian dan pastikan koneksi tetap tersedia.

06 · Status proyek

Versi awal ini menyediakan katalog 22 generator dan template dasar. Integrasi API/router langsung belum diaktifkan.

Catatan kompatibilitas

Generator menghasilkan teks konfigurasi, bukan melakukan perubahan ke router. Selalu cocokkan sintaks dengan dokumentasi resmi MikroTik dan versi perangkat.
